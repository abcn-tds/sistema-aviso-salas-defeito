# EletroSite
O ElectroSite é um sistema desenvolvido para auxiliar no gerenciamento de salas e equipamentos com defeitos. 
A plataforma permite o cadastro de salas, equipamentos e ocorrências de falhas, facilitando o acompanhamento 
dos problemas e o controle das manutenções realizadas.
